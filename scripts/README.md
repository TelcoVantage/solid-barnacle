# scripts/

`chat-ticket-script.script` is the importable script. It is generated by
`tools/build_script.py`; edit the generator and rebuild rather than editing the JSON by
hand, so the self-check keeps running.

Before importing:

1. Create the data actions `Create Ticket (v9)` and `Insert Data Table Row (Chat Logs)`
   and the `Chat Logs` data table in the target org.
2. Put their IDs into the file (generator flags or find-and-replace the two
   `REPLACE_WITH_*` tokens). The generator refuses non-GUID IDs.
3. Admin > Scripts > Import (or select the old script and Replace).
4. Open the imported script, confirm both Execute Data Action steps show their mappings,
   and Publish. Attach it to the queue's Message default script.

After the first successful import, export the published script and commit that export
here so git holds the editor's own output.
